# P7 面试与最终交付物

> 状态：代码交付面已完成；真实 benchmark 结果仍需 P5.1 外部 smoke、人工审核和 export。P7 不制作 Demo、视频或独立答辩稿。

## 1. 交付目标

陌生人应能在 10 分钟内完成三件事：看懂 Runtime 总架构，运行无凭据的确定性回归，沿 README 链接进入一个真实且已审核的 Dataset Run。README 只描述当前状态，不叙述历史方案演进。

## 2. 实施步骤

### S7.1：稳定入口

保留四个 CLI 动作，并让 CLI 与 WebUI 使用同一个 catalog、Job store 和结果读取器：

```bash
nanobot benchmark prepare --profile office-smoke
nanobot benchmark estimate --profile office-smoke --model-preset gpt-5-6-luna
nanobot benchmark run --profile ci
nanobot benchmark export --dataset-run <id>
```

- `ci` 只运行本地确定性门；不需要 Key、网络或 Langfuse。
- `prepare` 锁定数据/资产 revision、digest、许可证和 benchmark venv。
- `estimate` 在模型调用前给出样本与 token 估算。
- `run` 执行 Agent、evaluator、Score 和 checkpoint；`resume`/case rerun 复用已有结果。
- `export` 只接受已完成、必需 Score 齐全且审核完成的 Dataset Run，生成去敏快照。

### S7.2：结果归属

| 证据 | 唯一记录 |
| --- | --- |
| Runtime 安全、恢复、OpenXML、红队 | CI 与 `benchmarks/runtime/` 快照 |
| Agent trace、generation、tool、token、延迟 | Langfuse |
| Dataset Run、Judge Score、人工审核 | Langfuse |
| Job 阶段、case 进度、失败分类 | `~/.cache/nanobot/benchmarks/jobs/` |
| README 展示数字 | `benchmark export` 生成的受控区块 |

Mybot 不复制 Langfuse 的 Trace、Dataset、Score 管理功能；WebUI 评测中心只做选择、进度、恢复、删除和 deep link。

### S7.3：公平比较

Office 只保留 `officecli` Skill。Luna 与 DeepSeek V4 Flash 使用相同 Dataset、输入快照、Skill、Policy、Runtime profile 和 evaluator，分别建立 Dataset Run；Terra 只作为固定 Judge。报告至少分开展示 coverage、hard gate、质量分、token、延迟、工具成功率和 Agent 步数，不用 prompt 或路由偏袒某个模型。

### S7.4：README 结果页

README 必须包含：

1. 项目定位和当前能力边界；
2. 最短 quickstart、`ci` 回归命令和真模型 benchmark 入口；
3. 一张最终架构 Mermaid 图；
4. 当前确定性指标、证据文件和已知限制；
5. 已发布 Dataset Run 的 deep link 和由 `export` 生成的结果区块。

真实 Dataset Run 未完成前，结果区块必须明确写“外部证据待配置”，不得填估算值、历史失败值或手工数字。

## 3. 配置与发布顺序

1. 先跑 `nanobot benchmark run --profile ci`，确认本地 hard gate 通过。
2. 配置被测模型、Langfuse Project 和固定 Judge connection，完成 metadata-only preflight。
3. 锁定 benchmark 资产、许可证、LibreOffice 和 token 预算；smoke 通过前不跑 release。
4. 运行 smoke，等待 Score 回读并完成 Annotation Queue；中断时 Resume 原 Job，重试才创建新 Run。
5. 使用 `benchmark export` 更新 README，检查去敏内容和 Git SHA，再发布 release 结果。
6. 发布后恢复 `captureContent=false` 等安全默认值。

任何 Key、原始 Office 文件、个人信息和未获许可的内容都不能进入仓库、README、截图或 Trace。
