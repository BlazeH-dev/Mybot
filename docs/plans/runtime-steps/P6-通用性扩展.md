# P6 Research Skill 通用性验证

> 状态：选做，未排期、未实现。不属于冻结前必做或最终验收；若后续启动，控制在 1–2 天，只验证 Runtime 没有 Office 私有假设。

## 最小闭环

新增 `nanobot/skills/research/`：

1. 搜索并收集来源。
2. 写 `sources.json`。
3. 基于登记来源写 `research_report.md`。
4. 校验引用和来源覆盖。

明确不做知识库、向量数据库、复杂 UI 或专用工作流引擎。

## 必须复用的 Runtime

- P2 manifest、availability、disabled 语义。
- 现有 web/network 工具与 SSRF hard boundary。
- P3 policy/InteractionRequest；登录态、远程写和外发走 approval。
- P4 artifact/lineage：report 指向 sources。
- P5 trace/eval，不新增 Research 私有事件通道。
- P8 Subagent 为可选策略，不强制每次使用。

网页和搜索摘要视为 untrusted content；报告只能引用 `sources.json` 中登记的来源。红队断言恶意来源不能诱导敏感读取、越界写入或未确认外发。

## Subagent 验证

如使用 child 收集不同来源：

- 最多 5 个直接 child，禁止嵌套，权限只收紧。
- child 不设置 token、总时长或工具调用配额；保留取消、单次 LLM timeout、数量限制和循环熔断。
- child 只返回结构化摘要、来源和 artifact，父 Agent 统一核对和成文。
- 必须与单 Agent 顺序收集比较成功率、时长和 token。
