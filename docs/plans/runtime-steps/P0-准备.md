## 固定 Office fixture

目录：`tests/fixtures/office_python/`

- `create_docx.json`、`create_xlsx.json`、`create_pptx.json` 是 OfficePython request template。
- `sample.docx`、`sample.xlsx`、`sample.pptx` 是可由 `make_fixture.py` 重生的最小 OpenXML 样本。
- fixture 只表达通用段落/表格/列表、工作表/公式/图表、幻灯片/基础布局，不携带周报业务偏置。
- `tests/skills/test_office_python.py` 负责三格式 create/inspect/query/apply/validate、自检和 shared facts 回归。

旧 `tests/fixtures/office_weekly/`、expected metrics/constraints 和业务 DSL 已随 P1.1 删除；P5 Core
的固定 `office_baseline` 使用中立 XLSX 与 `total_amount=30` 继续验证 artifact、OpenXML 和数字一致性。
