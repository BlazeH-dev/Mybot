## 必须交付

### 固定 Office fixture

目录：`tests/fixtures/office_weekly/`

- `sales_data.xlsx` 与可复现生成脚本 `make_fixture.py`。
- `meeting_notes.md`。
- 人工核对的 `expected_metrics.json`。
- `expected_constraints.json`，含页数和必含内容等约束。
- `test_fixture.py`，确定性复算 workbook 指标。

规则：

- 数据保持小而真实，数值便于人工复核。
- `office-automation` 与 `officecli` 使用同一输入、expected metrics 和公共约束；不要求共享 DSL。
- xlsx 必须可由生成脚本重建并被 `openpyxl` 重新打开。

### GitHub Actions 回归门

`.github/workflows/ci.yml` 在 Python 3.11 下执行：

- `ruff check nanobot/`
- P0 fixture 与二开相关确定性 pytest smoke
- S5.0 完成后纳入轻量 cassette smoke

全量上游测试受网络、密钥、端口和 home 写入影响时，CI 只圈定确定性子集，并在 workflow 中说明边界。
